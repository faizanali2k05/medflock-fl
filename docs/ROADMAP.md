# Remaining integrations

The research beta provides configurable training, dataset contracts, checksummed continuation, GraphQL operations, a live console and separate API/worker delivery.

Clinical readiness now includes executable LoRA distillation, cohort evaluation and review APIs, image/waveform feature adapters, and authenticated TLS Flower preparation. See [READINESS.md](READINESS.md) for usage, limitations and external prerequisites.

- Independent clinical evaluation and qualified reviewer sign-off.
- Hospital-authorized deployment, target-host capacity/proxy inspection and backup restore exercise.
- Dashboard orchestration of remote Flower nodes and federated LLM adapter training.
- High-availability scheduling and incremental schema migration when required by deployment scale.

Simulated federation and synthetic transformer tests must remain labelled as such in every result.
